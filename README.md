# 🧾 BillNest - Gestionnaire de Facturation

BillNest est une application desktop développée en **C# / WPF** suivant l'architecture **MVVM**. Elle permet de gérer une base de données clients et d'automatiser la création de factures professionnelles.

## 🧩 Fonctionnalités
- **Gestion Client :** CRUD complet (Ajout, Lecture, Mise à jour, Suppression).
- **Calculs automatiques :** Utilisation de requêtes **LINQ** pour le suivi des montants dûs.
- **Génération PDF :** Création de factures automatiques avec la bibliothèque **iText 9**.

## 🛠️ Technologies utilisées
- **Langage :** C# (.NET)
- **Interface :** WPF / XAML
- **Base de données :** MySQL (via XAMPP)
- **ORM :** Entity Framework Core

Le projet a été réalisé dans le cadre de ma formation au CESI.
